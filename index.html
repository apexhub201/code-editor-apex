GUIDE
Support & User Guide for APEX HUB Editor

1. Login / Register

Register new account:

  • Click "Sign In" button at top right
  • Select "Register" tab
  • Fill in: Display name, Email, Password
  • Click "Register"

Login:

  • Method 1: Use registered Email + Password
  • Method 2: Click "Sign in with Google" for quick login

2. Write New Script

  • Script name: Name your script
  • Password: Enter password to protect your script
  • Code Editor: Write your Lua code in the editing area
  • Press Tab to indent code (auto adds 4 spaces)

3. Save Script & Create RAW Link

Normal save:

  • Click "Save & Create RAW" button
  • Script will be saved to your library

Create RAW Link (share link):

  • Important Note popup will appear
  • Click "Continue" to proceed
  • RAW link will appear in the input box
  • Click "Copy URL" to copy the share link

4. Key System (Verification)

When Key is required, "Get Verification Key" popup will appear:

Get Key from Platoboost (primary):

  • Click "Get Key from Platoboost"
  • Follow instructions on the opened website
  • Copy the received Key
  • Paste Key into "Enter Your Key" field
  • Click "Verify Key"

Get Key from Link4m (backup):

  • Click "Get Key from Link4m"
  • Can click "Change" to switch link (max 3 times/day)
  • Go to the provided link, copy Key
  • Paste Key and click "Verify Key"

5. Manage Scripts (Library)

All your scripts appear in "Script Library" below.

  • Edit: Open script in editor for editing
  • Copy: Copy entire code content
  • ... (three-dot menu): Rename, Delete, Copy RAW URL
